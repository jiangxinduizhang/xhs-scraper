## uiautomator2 特征隐藏

### 问题：uiautomator2 的可检测特征

uiautomator2 在设备上会安装辅助 APK（`io.appium.uiautomator2.server`），
并通过 accessibility service 控制设备。小红书可能检测以下特征：

| 特征 | 检测方式 | 风险等级 |
|------|---------|---------|
| `io.appium.uiautomator2.server` APK 存在 | 检测已安装包列表 | 高 |
| Accessibility Service 激活状态 | 系统 API 查询 | 中 |
| `ro.debuggable=1` 属性 | 系统属性检测 | 低 |
| USB 调试模式开启 | `Settings.Global.ADB_ENABLED` | 低 |
| 连续规律性操作节奏 | 行为分析 | 高 |

### Magisk DenyList 配置

通过 Magisk DenyList 对小红书隐藏 root 相关特征：

```
Magisk Manager → 设置 → Zygisk → 开启
Magisk Manager → DenyList → 开启
DenyList → 添加 com.xingin.xhs（小红书包名）
```

这会对小红书隐藏：
- Magisk 相关文件和进程
- root 权限特征
- Zygisk 注入痕迹

### 隐藏 uiautomator2 Server

```bash
# 方案：通过 Magisk 模块重命名/隐藏 APK
# 或：在不需要控制时卸载，需要时重新安装
adb uninstall io.appium.uiautomator2.server
adb uninstall io.appium.uiautomator2.server.test

# 仅在抓取窗口内安装
python -m uiautomator2 init  # 自动推送
```

## 行为随机化策略清单

### 操作层随机化

| 策略 | 实现方式 | 目的 |
|------|---------|------|
| 坐标抖动 | 点击坐标 ±5px 随机偏移 | 避免完全相同的点击坐标 |
| 滑动速度变化 | duration 0.3~0.6s 随机 | 避免机械化滑动速度 |
| 操作间隔随机 | 0.5~1.5s 均匀分布 | 避免固定节奏 |
| 阅读停顿 | 20% 概率 2~4s 长停顿 | 模拟用户阅读内容 |
| 打字速度 | 50~150ms/字 随机 | 模拟真实打字速度 |
| 滑动幅度 | 屏幕高度 30%~60% 随机 | 避免固定滑动距离 |

## 风控触发处理

### 验证码识别

#### 滑块验证码

```python
# 方案 A：使用 ddddocr 识别滑块距离
# pip install ddddocr

import ddddocr
import base64

def solve_slider_captcha(d: u2.Device) -> bool:
    """处理滑块验证码"""
    # 截图
    screenshot = d.screenshot(format='pillow')

    # 识别滑块位置
    ocr = ddddocr.DdddOcr(det=False, ocr=False, show_ad=False)
    slider = d(resourceId="com.xingin.xhs:id/slider_icon")
    target = d(resourceId="com.xingin.xhs:id/slider_target")

    if not slider.exists() or not target.exists():
        return False

    slider_rect = slider.info["bounds"]
    target_rect = target.info["bounds"]

    # 计算滑动距离
    distance = target_rect["left"] - slider_rect["left"]

    # 模拟人工滑动（先快后慢，带抖动）
    _human_like_slide(d, slider_rect, distance)
    time.sleep(1.5)

    return True


def _human_like_slide(d, start_rect, distance):
    """模拟人工滑动轨迹"""
    start_x = (start_rect["left"] + start_rect["right"]) // 2
    start_y = (start_rect["top"] + start_rect["bottom"]) // 2

    # 分段滑动：先快速滑动 80%，再缓慢精调
    fast_distance = int(distance * 0.8)
    slow_distance = distance - fast_distance

    d.touch.down(start_x, start_y)
    time.sleep(0.1)

    # 快速段
    for i in range(10):
        d.touch.move(start_x + int(fast_distance * (i+1) / 10) + random.randint(-2, 2),
                     start_y + random.randint(-2, 2))
        time.sleep(0.02)

    # 慢速精调段
    for i in range(5):
        d.touch.move(start_x + fast_distance + int(slow_distance * (i+1) / 5) + random.randint(-1, 1),
                     start_y + random.randint(-1, 1))
        time.sleep(0.08)

    d.touch.up(start_x + distance, start_y)
```

### 风控触发后的处理策略

```python
RISK_RESPONSES = {
    "slider_captcha": solve_slider_captcha,
    "image_captcha": lambda d: MidsceneBridge().handle_captcha(d),
    "phone_verify": _handle_phone_verify,    # 需要人工处理
    "account_banned": _handle_ban,
}

def handle_risk(d: u2.Device, risk_type: str) -> bool:
    """处理风控触发"""
    handler = RISK_RESPONSES.get(risk_type)
    if handler:
        success = handler(d)
        if not success:
            # 处理失败：暂停当前账号，切换新账号
            logger.warning(f"风控处理失败: {risk_type}，暂停当前账号")
            return False

    # 处理完后增加等待时间
    time.sleep(random.uniform(30, 60))
    return True

def _handle_ban(d: u2.Device) -> bool:
    """账号被封处理"""
    logger.error("账号疑似被封，停止当前账号操作")
    # 发送告警（Bark/企业微信等）
    send_alert("账号被封告警", "请检查账号状态")
    return False
```

## 风险等级与应对

| 风险 | 触发条件 | 应对措施 |
|------|---------|---------|
| 频率过高 | 操作间隔过短 | 严格执行随机延时，降低速度 |
| 设备指纹 | 固定 device_id | 定期重置 advertising_id |
| IP 风控 | 固定家庭 WiFi | 考虑使用移动网络或代理 |
| 账号异常 | 单账号操作量过大 | 严格遵守每日上限，账号轮换 |
| APP 更新 | 元素 ID 变化 | 更新时暂停，检查 XPath |
| 证书更新 | SSL 证书变化 | 重新提取并安装 CA 证书 |

## Mac 端依赖

### 系统要求
- macOS 12+
- Python 3.11+
- Node.js 18+（Midscene 需要）
- ADB（Android Debug Bridge）

### 安装步骤

```bash
# 1. 安装 Homebrew（已有跳过）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. 安装 ADB
brew install android-platform-tools

# 3. 安装 Python 依赖
pip install uiautomator2 mitmproxy

# 4. 安装 uiautomator2 初始化工具
python -m uiautomator2 init  # 会推送 apk 到连接的设备

# 5. 安装 Node.js（用于 Midscene）
brew install node

# 6. 安装 Midscene
npm install -g @midscene/cli
# 或在项目目录下
npm install @midscene/web
```

## SSL Pinning 绕过方案

### 方案：Magisk 安装系统证书（推荐）

此方案在 root 设备上最稳定，APP 重启后仍有效，无需每次运行时注入。

**步骤：**

```bash
# 1. 生成 mitmproxy CA 证书（首次运行 mitmproxy 会自动生成）
mitmproxy  # 首次运行后退出，证书生成在 ~/.mitmproxy/

# 2. 获取证书 hash 格式文件名
openssl x509 -inform PEM -subject_hash_old \
  -in ~/.mitmproxy/mitmproxy-ca-cert.pem | head -1
# 假设输出为 c8750f0d

# 3. 重命名证书文件
cp ~/.mitmproxy/mitmproxy-ca-cert.pem c8750f0d.0

# 4. 推送到手机系统证书目录
adb push c8750f0d.0 /sdcard/
adb shell su -c "mount -o rw,remount /system"
adb shell su -c "cp /sdcard/c8750f0d.0 /system/etc/security/cacerts/"
adb shell su -c "chmod 644 /system/etc/security/cacerts/c8750f0d.0"
adb shell su -c "mount -o ro,remount /system"
adb reboot
```

**验证：**
```bash
# 重启后检查证书是否安装
adb shell ls /system/etc/security/cacerts/ | grep c8750f0d
```

> 注意：若使用 MagiskTrustUserCerts 模块，可简化为：
> 在手机「设置 → 安全 → 加密与凭据 → 安装证书」安装 mitmproxy CA，
> 模块会自动将用户证书提升为系统证书。

### 小红书 SSL Pinning 情况
小红书使用了证书锁定（Certificate Pinning），仅安装系统证书可能不够。
若遭遇 SSL 握手失败，需额外处理：

```bash
# 方案 A：使用 Frida + objection 绕过（需要 frida-server 在设备运行）
pip install frida-tools objection
adb push frida-server /data/local/tmp/
adb shell su -c "chmod +x /data/local/tmp/frida-server && /data/local/tmp/frida-server &"
objection -g com.xingin.xhs explore --startup-command "android sslpinning disable"

# 方案 B：Xposed 模块 TrustMeAlready / JustTrustMe++（需要 LSPosed）
# 在 LSPosed 中启用对应模块，针对小红书包名 com.xingin.xhs
```

## 验证脚本

### scripts/verify_env.sh

```bash
#!/bin/bash
echo "=== 环境验证 ==="

# 1. ADB 连接
echo "[1] ADB 设备检测..."
adb devices
if adb devices | grep -q "device$"; then
    echo "✓ ADB 设备已连接"
else
    echo "✗ 未检测到 ADB 设备"
fi

# 2. Root 验证
echo "[2] Root 权限验证..."
result=$(adb shell su -c id 2>/dev/null)
if echo "$result" | grep -q "uid=0"; then
    echo "✓ Root 权限正常: $result"
else
    echo "✗ Root 权限异常"
fi

# 3. mitmproxy
echo "[3] mitmproxy 检测..."
if command -v mitmproxy &> /dev/null; then
    echo "✓ mitmproxy $(mitmproxy --version | head -1)"
else
    echo "✗ mitmproxy 未安装"
fi

# 4. uiautomator2
echo "[4] uiautomator2 检测..."
python3 -c "import uiautomator2; print('✓ uiautomator2', uiautomator2.__version__)" 2>/dev/null || echo "✗ uiautomator2 未安装"

# 5. 证书验证（手机端）
echo "[5] 系统证书检测..."
cert_count=$(adb shell ls /system/etc/security/cacerts/ | wc -l)
echo "  系统证书数量: $cert_count"
if adb shell ls /system/etc/security/cacerts/ | grep -q ".0$"; then
    echo "✓ 系统证书目录正常"
fi

echo "=== 验证完成 ==="
```
